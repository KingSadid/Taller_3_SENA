Capítulo I · El manifiesto

Una función es una promesa con nombre

Recibe algo, hace una sola cosa y devuelve algo. El resto del programa confía sin mirar adentro.

“Las funciones deben ser pequeñas. Y más pequeñas que eso.” — inspirado en Clean Code, R. C. Martin

En PHP se declaran con function, pueden tipar entradas y salidas, tener valores por defecto y vivir en la biblioteca nativa (+1000 funciones) o nacer de tu mano para tu sistema.

PHP · anatomia.php
function registrarUsuario(string $nombre, string $email): array {
    $limpio = trim($email);
    if (!filter_var($limpio, FILTER_VALIDATE_EMAIL)) {
        throw new InvalidArgumentException("Email inválido");
    }
    return guardarUsuario($nombre, $limpio);
}
